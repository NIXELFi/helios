# 28 — 2.4.0 Polish Bundle

**Version:** 2.4.0
**Date:** 2026-05-06

The XY analysis plot (entry 27) is the headline feature of 2.4.0, but a long list of UI / UX / asset improvements landed in the same release. They're bundled here rather than split into individual entries because they were all built and tested together.

## What

### App icon refresh

The placeholder yellow square is gone. The Helios app icon is now the panther logo on a yellow squircle (macOS Big Sur–style 22.37% corner radius). All platform-specific sizes regenerated from a single 1254×1254 source — `apps/desktop/src-tauri/icons/source.png` is checked in so future re-runs of `pnpm tauri icon …` are deterministic.

### Steering wheel widget — real wheel art

The vector three-spoke abstraction is replaced with a stylized PNG of the actual Helios steering wheel: panther logo in the center, butterfly grips, yellow buttons + encoders. The widget canvas keeps drawing the limit ring, tick marks, L/R labels, numeric readout, and over-limit color logic; only the rim/spokes/hub portion is now the bitmap, drawn rotated by the steering angle.

### Global datums + zoom across all time charts

A new `ViewStateEmitter` (sibling to the existing `CursorEmitter`) carries two pieces of session-scoped state used by every chart:

- **Datums** — vertical reference markers pinned to specific timestamps. Drop one with **shift+click** anywhere on a strip chart; it shows up as a red-orange vertical line + small "T+12.4s"–style label, and as a crosshair + dot at the matching `(x, y)` on every XY plot in the workspace. Survives workspace switches.
- **Zoom** — global X-axis range. **Shift+drag** on any strip chart selects a window; release zooms *all* strip charts to that window. **Double-click** anywhere on a strip chart resets the zoom. The XY plot's data pipeline automatically respects the zoom, so zooming into a corner makes XY plots show only that corner's samples. Playback wraps at the zoom edge instead of the session edge when zoomed.

The header gets two bright yellow pills that surface the current state and reset it in one click — `Reset zoom` when zoomed, `Clear datums (N)` when datums exist. Both are visible in view *and* edit mode so they can't be lost behind a UI state.

### Workspace tab strip — custom scrollbar + visual separation

- Native horizontal scrollbar hidden cross-platform (kills the chunky macOS thumb, the auto-fading Windows thumb, and the layout-shifting Firefox thumb in one go) and replaced with a **thin yellow custom thumb** pinned 8 px below the strip. Drag-to-scroll. Width + position track `scrollLeft` via a ResizeObserver (with a JSDOM stub so widget tests don't blow up).
- **Vertical dividers** added on both sides of the tab bar so the strip is visually separated from the session label on the left and the toolbar on the right, even when the tabs overflow and butt up against neighboring controls.

### Header focus mode while editing

In edit mode the entire header rearranges:

- Session label, divider, and tab bar all hide.
- Toolbar (Channels / Math / Done editing / + Add tile / Snap / Reset all) centers via `mx-auto` so the editing controls dominate the bar.
- Playback controls, updater pill, and cursor clock all hide as view-mode chrome.
- The yellow zoom/datum reset pills stay visible (they're system state, not chrome).

The result: when you're laying out tiles you only see the things you can act on.

### FpsCounter footer pill

A subtle `60fps · 16ms` readout in the existing footer text, driven by a 500 ms sliding rAF window. Color-coded — inherits the muted footer color when ≥55 fps; goes yellow at 30–55, red below 30. The "ms" half reports the worst single frame in the window so a one-off jank surfaces even if the average is fine.

### Updater pill — version actually shows

The "✓ v—" rendering of the updater pill (when on the latest version) is fixed. The previous code tried to read the current version from a Tauri-internals path that never existed in 2.x and silently returned an empty string. Now it uses `@tauri-apps/api/app#getVersion()` directly.

### macOS trackpad rubber-band on horizontal swipe — disabled

`overscroll-behavior-x: none` + `overflow-x: hidden` on `<html>`/`<body>` kills the WKWebView two-finger horizontal-swipe rubber-band that was translating the entire app sideways on macOS. Nested horizontal scrolls (the workspace tab strip, charts, etc.) keep working because they have their own `overflow-x: auto` containers.

## Files of note

- `packages/lib/src/view-state.ts` — pub/sub holder for datums + zoomRange.
- `packages/widgets/src/strip-chart/render.tsx` — datum/zoom interaction handlers + rendering.
- `apps/desktop/src/components/WorkspaceTabBar.tsx` — custom scrollbar + thumb drag math (`computeThumb` is exported and unit-tested).
- `apps/desktop/src/App.tsx` — `ViewStatePills`, `FpsCounter`, header layout, edit-mode hide.
- `apps/desktop/src-tauri/icons/source.png` — single source of truth for the app icon.

## Tests added

- `packages/lib/tests/view-state.test.ts` — 11 tests covering ViewStateEmitter (subscribe/unsubscribe, addDatum dedupe + sort, removeDatum, clearDatums, setZoom guard against zero/negative width, no-op silence).
